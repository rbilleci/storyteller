# Changelog

## 0.1.0

Initial experimental source release.

- Deterministic Black Sword Hack rules, audited file-backed campaign storage,
  and an MCP server.
- Strands narrator with typed decisions, tool-surface checks, fiction settlement,
  and guarded delivery.
- Terminal and replay channels, multilingual catalogs, and the Black Estuary setting.
- Offline regression suites and opt-in live probes.
- GPL-3.0-only project license with CC BY 4.0 SRD attribution.

See [known limitations](DEFERRED.md) for unsupported features and behavior limits.
